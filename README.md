# [Squash]!

[Squash] is an image compression web app that reduces image sizes through numerous formats.

# Privacy

Squash is private by default:

- **No uploads.** Compression happens entirely inside your browser, so your
  images never leave your device.
- **No tracking.** Squash does not include analytics, ads, or third-party
  trackers.
- **No accounts, no storage.** You don't sign in, and nothing is saved on our
  side.

When you close the tab, everything is gone.

# Developing

To develop for Squash:

1. Clone the repository
1. To install node packages, run:
   ```sh
   npm install
   ```
1. Then build the app by running:
   ```sh
   npm run build
   ```
1. After building, start the development server by running:
   ```sh
   npm run dev
   ```

For architecture notes and feature-development guidance, see the [developer documentation](docs/README.md).
